User Restriction on Product Access

User Restriction on Product Access by Allowing Selected Products or Categories

Available Key Features
  • This module allows to put restriction on products access from user to do any kind of operation.
  • User can not see any products if not allowed by the Product Restriction Manager.
  • Product restriction manager group is used to access all products and can see allowed products tab under user.
  • Product restriction given by two ways By products & By product categories.
  • Restriction by Products: need to add products directly in below "Allowed Product" Section and only that products are accessible in back end to that User
  • Restriction by Product Categories: need to add Categories directly in below "Allowed Category" Section. All products of given category and its child category are accessible in back end to that User
1. Product Restriction Manager

New group "Product Restriction Manager" to manage product restriction with users.
2. Product Restriction by Products

A). Allow product selection to give access of products to User


B). Only see allowed products by product restriction manager


C). Only see allowed product variants by product restriction manager

3. Product Restriction by Product Categories

A). Allow categories selection to give access of products to User


B). User get access of all products of allowed categories as well child of allow categories


C). User get access of all product variants of allowed categories as well child of allow categories
